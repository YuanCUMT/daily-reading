  还差一步：没有找到 Node.js
============================================================

这个程序需要 Node.js 才能运行。只要装一次，以后不用管。

怎么办：
  1. 打开  https://nodejs.org
  2. 下载 LTS 版本（页面左边那个按钮）
  3. 一路「下一步」装完
  4. 关掉这个窗口，重新双击 start.cmd

装完还是提示这个？
  - 重启一次电脑（新装的程序需要重新读取环境变量）
  - 或者在命令行里输入  node -v  看有没有版本号输出
