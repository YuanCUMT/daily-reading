Features

不是背单词 App，
是把单词用起来的那一步。

背和用之间隔着一个东西：语境。这里做的就是补上那一步。

⌗

截图就能进词表

拖几张截图进来，按字号挑出单词卡上的大字，界面文字和例句自动丢掉，拼错了还会用模型修一遍。

✎

两种模式，两种用途

复习模式把今天 40 个词全塞进去，句子短、记得住；真题模式只挑 15 个，写 400 词的社科议论文，带让步与反驳。

◎

点词即查，不用切窗口

正文里点任何单词、拖选任何短语就弹释义，附考研常考义项与搭配。收藏的词在正文里立刻变绿。

▤

三个完整的单词本

每日导入的词、收藏的生词、收藏的短语分开放。按天分组或按字母排，缺释义的词一键补齐，补一次永久缓存。

Reading flow

背过的词，第二天还会遇见。

昨天导入的词，今天生成文章时仍然在候选池里。你不需要记得自己背过什么 —— 它按遗忘曲线把旧词翻出来，塞进新的语境。

Setup

Windows 上，三步开始。

STEP 01
装 Node.js 18+

唯一的前提。截图识别用的是 Windows 自带 OCR，不用另装任何东西。

STEP 02
双击 start.cmd

浏览器自动打开 127.0.0.1:8787，右上角 ⚙️ 填一个 DeepSeek API Key。

STEP 03
导入今天的词

拖截图或直接粘贴，勾选要用的词，点「生成文章」。明天它还认得你昨天背了什么。

今天背的词，别只停在卡片上。
